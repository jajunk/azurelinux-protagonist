Architecture path

The intended stack builds upward from a hardened RPM base.

  1. 01 Azure Linux 3.0 base

    RPM packaging, hardened defaults, reproducible source/signature handling, and the Go-based toolkit.

  2. 02 Mesa rebuild

    Enable and validate Intel iris and AMD radeonsi Gallium driver paths.

  3. 03 Desktop prerequisites

    Package or verify components such as libseat, libdisplay-info, and desktop portals.

  4. 04 KDE session core

    Bring up the session, display manager path, compositor stack, settings, and portal integration.

  5. 05 KDE shell and apps

    Layer Plasma workspace, system settings, file management, terminal, applets, and product defaults after the core path works.
